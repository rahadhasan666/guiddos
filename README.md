# 🔥 DDoS Tool - Custom Edition (GUI Based)

A custom-built GUI-based DDoS stress testing tool developed using Python, `asyncio`, and `aiohttp`. This tool simulates high-performance HTTP request loads to a target URL for educational, research, or load-testing purposes.

> ⚠️ **Disclaimer:** This tool is strictly for educational and authorized testing purposes only. Unauthorized usage may violate laws and ethical standards.

## 🚀 Features

- Simple GUI interface with `tkinter`
- Multi-threaded async DDoS mechanism using `asyncio` and `aiohttp`
- Target any valid domain or IP
- Random User-Agent and IP address generation
- Up to **800 Requests Per Second**
- "💥 Bomb dropped" log for each hit
- Developer credit with GitHub button

## 🛠️ Requirements

This project requires **Python 3.8+** & **Kali Linux** or Any Debian Based OS

## Run Locally

Clone the project

```bash
  git clone https://github.com/rahadhasan666/guiddos.git
```

Go to the project directory

```bash
  cd DDoS
```

Install dependencies

```bash
  pip install aiohttp
```

Requirements file

```bash
  pip install -r requirements.txt
```

Run command
```bash
  python3 DDoS.py
```
